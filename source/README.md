# TV Desk для Android

APK написан на Java и использует штатный интерфейс Android. Каталог содержит проект для Android Studio с Android SDK 35 и JDK 17. Откройте папку source в Android Studio, разрешите синхронизацию Gradle и выполните Build APK. В Windows из этой папки можно выполнить `gradlew.bat :app:assembleDebug`, в Linux или macOS — `./gradlew :app:assembleDebug`. При первом запуске Gradle и компоненты SDK загружаются отдельно.

Идентификатор приложения — `tech.krasivo.tvdesk`. Минимальная версия — Android 7. Вложенный APK подписан пилотным ключом. Для собственной серии установок соберите приложение с вашим ключом подписи и храните его для обновлений. Android требует одинаковую подпись для обновления установленной версии. При переходе с пилотной подписи сохраните профиль в панели, удалите пилотную сборку, установите свою, импортируйте профиль и привяжите USB заново.

Исходный код панели ноутбука находится в `../Laptop/Android-Bluetooth.html`. Страница автономна и использует Web Serial для сопряжённого устройства Bluetooth Classic. Сервис RFCOMM использует UUID `b510816b-29c8-4250-968a-1d598d88be74`. События и запросы передаются в UTF-8 в формате JSON, по одному объекту в строке. Персональная настройка сохраняется средствами Android на конкретном ТВ.

`Home.java` отвечает за домашний экран, диалог подтверждения, действия в настройках и обнаружение съёмного тома. `Apps.java` получает каталог из PackageManager и хранит профиль. `Link.java` открывает защищённый сокет RFCOMM, ожидает разрешения на телевизоре и закрывает сеанс по таймеру. Изменяющие команды принимаются, когда TV Desk открыт на экране. Полный каталог запрашивается для управления приложениями. Права администратора, доступ к файлам USB и доступ в интернет не запрашиваются.

Файлы Gradle Wrapper версии 8.9 поставляются проектом Gradle под лицензией Apache 2.0. Текст включён в `gradle/wrapper/LICENSE.txt`.

Версия Android-клиента 0.3 использует прежние идентификатор пакета, пилотную подпись и хранилище профиля. Часы используют формат и время системы. Город относится к профилю TV Desk.
